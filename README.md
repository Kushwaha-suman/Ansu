# 💗 Her Heart Beats in Code

A simple romantic animated webpage built with **HTML, CSS, and JavaScript**.  
It features an animated particle heart effect, smooth text animations, and a personalized love message.  

---

## 🌐 Demo  
👉 [Live Demo](https://kushwahaaditi.netlify.app/)  

---

## ✨ Features  
- ❤️ Heart particle animation using `<canvas>`  
- 🎨 Smooth fade-in message effect  
- ✍️ Beautiful Google Fonts (Pacifico, Archivo, Inter, Poppins)  
- 🌑 Dark theme background  
- 📱 Mobile-friendly design
